prototype API/frontend code, historical preflight notes, and development artefacts.

These files are retained for research provenance but are not part of the
canonical dissertation pipeline or final evaluation.

For the current implementation and reported results, see the root README,
`dissertation-behaviour-recognition/src/`,
`dissertation-behaviour-recognition/scripts/README.md` and
`dissertation-behaviour-recognition/reports/`.
