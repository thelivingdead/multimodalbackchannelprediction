# Figures

Generated by `python scripts/make_figures.py --all`.

- PNG 300 DPI for the dissertation
- JPG 300 DPI for GitHub
- No silent overwrite (`--force` required)
- Missing experiments are skipped, never faked

Typical Stage B outputs:

| folder | contents |
| --- | --- |
| `dataset/` | split sizes (and diversity grid if real mp4s exist) |
| `annotations/` | gold timelines, class counts |
| `pilot_nod/` | pitch/yaw/roll + gold; TP/FP/FN windows |
| `rule_baseline/` | metrics, heatmap, per-video F1, IoU bars, pitch vs background |
| `error_analysis/` | extra TP/FP/FN pitch windows |
| `final_results/` | pipeline schematic (no scores) |
